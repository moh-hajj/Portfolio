Capstone Project

Hajjar Audit & Advisory Ltd — Enterprise Network Design & Implementation

End-to-end design and build of a three-site, 76-user network for a regulated auditing firm.

Delivered the full project lifecycle for a simulated 76-user Maltese audit practice spanning Birkirkara HQ, St Paul's Bay, and Paola — from business and requirements analysis through design, costing, implementation, hardening, testing, and formal handover.

  • Design & planning: floor plans with active and passive device placement, server room and branch cabinet layouts, a SASE-based zero-trust security architecture, and a €192,710 Bill of Quantity with a 556 man-hour resource plan scheduled in Microsoft Project.
  • Network build (Packet Tracer): three LANs across 15 subnets with service-based VLANs for data, voice, printing, and CCTV; router-on-a-stick inter-VLAN routing over 802.1Q sub-interfaces; OSPF across the site-to-site WAN links; trunking and port security on every access switch.
  • Server & identity (Windows Server 2025): promoted HQ-DC01 as domain controller for hajjaradvisory.local, built the departmental OU tree with global security groups, joined and managed domain workstations, and deployed user- and computer-scoped GPOs.
  • AD security hardening: password complexity and history, account lockout thresholds, advanced logon auditing, Windows Defender Firewall domain profile, and Restricted Groups least-privilege enforcement — each control functionally tested and evidenced.
Cisco Packet Tracer, Windows Server 2025, Active Directory, Group Policy, VMware, OSPF, VLANs, Microsoft Project
Network Administration

Server Management & WAN Services — Multi-DC Active Directory Deployment

Redundant domain controllers, disaster recovery, VPN remote access, and inter-site replication topology.

Built a resilient Windows Server estate for the same three-site audit scenario, focused on high availability, recoverability, and secure remote access rather than network design.

  • AD redundancy & replication: deployed and promoted a second domain controller into the existing Mohamadhajjar.local domain with AD DS and DNS, cleared prerequisite validation, then proved multi-master replication by confirming an OU created on one DC had propagated to the other.
  • Backup & disaster recovery: configured a permissioned network share on the secondary server and ran a full bare-metal Windows Server Backup of the primary DC — system state, EFI system partition, and 10.23 GB of volume data — verified as successful.
  • VPN remote access: installed the Remote Access role (DirectAccess/VPN RAS with Routing), configured RRAS across separate LAN and external adapters with a static client address pool, granted dial-in permission on a domain account, and confirmed an authenticated client session in the Remote Access console.
  • AD Sites and Services: created two named sites, mapped each to its own subnet, relocated the backup DC into the correct site, and renamed the IP site link to bring inter-site replication cost and schedule under explicit control.
  • Server Core administration: installed Windows Server 2022 Core with no GUI, then set the static IP and DNS and joined the domain entirely through sconfig and the command line, verifying the computer object in Active Directory Users and Computers.
  • WAN design report: recommended a hub-and-spoke topology with headquarters as the hub and both branches as spokes over site-to-site VPN/SD-WAN, assessed against full mesh, partial mesh, SD-WAN, and cloud-first alternatives, with mitigations for the hub as a single point of failure.
Windows Server 2025, Windows Server 2022 Core, Active Directory, DNS, AD Sites and Services, RRAS/VPN, Windows Server Backup, VMware Workstation
